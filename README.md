Bash Playground

A collection of Bash scripts created while learning and experimenting with shell scripting on Termux and Linux.

This repository is my personal playground for practising programming concepts, automating simple tasks, and exploring what can be done with the terminal.

What I'm Learning

- Variables and user input — storing values and using "read"
- Conditionals — making decisions with "if" and "else"
- Loops — repeating tasks with "for" and "while"
- Functions — organizing reusable code
- Case statements — building interactive menus
- Arguments and flags — passing options and parameters to scripts
- File handling — creating, reading, copying, and searching files
- Terminal effects — experimenting with colors and animations
- Linux commands — practising everyday terminal operations

Getting Started

Requirements

- Bash
- Termux or a Linux environment
- A terminal editor, such as Nano

Running a Script

Clone the repository:

git clone https://github.com/YOUR_USERNAME/bash-playground.git
cd bash-playground

Run a script directly with Bash:

bash path/to/script.sh

Or make it executable:

chmod +x path/to/script.sh
./path/to/script.sh

Replace the example path with the script you want to run.
